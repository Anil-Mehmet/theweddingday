Düğün Davetiyesi 💍

Zarf açılış animasyonlu, mobil uyumlu, tek sayfalık dijital düğün davetiyesi. WhatsApp üzerinden paylaşılmak üzere tasarlandı.

**Canlı site:** https://anil-mehmet.github.io/theweddingday/

## ✨ Özellikler

- 🖇️ Sayfa açılışında **2 saniye sonra açılan zarf animasyonu**
- 🌸 Gül & gökyüzü temalı, tamamen özel tasarım arka plan
- ⏳ Düğün tarihine göre **canlı çalışan geri sayım** (gün / saat / dakika / saniye)
- 📍 Google Maps'e bağlı **"Yol Tarifi Al"** butonu
- 🖼️ Fotoğraf galerisi alanı
- 📱 Uçtan uca **mobil uyumlu** tasarım
- ⚡ Herhangi bir framework veya build aracı gerektirmez — saf HTML, CSS ve JavaScript
